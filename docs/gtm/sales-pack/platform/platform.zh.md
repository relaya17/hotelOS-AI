## 开场

HotelOS AI 不是又一个酒店聊天机器人。它被建成 **Intelligence Layer**：在现有 PMS 之上的酒店集团操作系统——先用可衡量的试运行，再扩展域。

## 四大支柱

### 能力
面向网络的操作系统——不是又一个单部门应用。  
Executive、Admin、Work、Guest 共享同一核心。简报、Incident Center、预测、预测性维护、带 HITL 的收入、多语聊天，以及通过单一 AI Gateway 的智能体。

### 可靠性
AI 建议 — 人审批 — 系统执行。  
金钱与房价走 Suggest → Approve → Act。没有黑箱。集团因此能在无惧财务委员会的情况下关闭试运行。

### 稳定性
位于 PMS 之上的一层——不是 18 个月的 rip-and-replace。  
Opera / Protel / Fidelio / Clock 仍是预订的真实来源。实施风险更低，价值更快显现。

### 创新
按品类打造：酒店 Intelligence Layer。  
不是 Excel 上的 ChatGPT，也不是昨天的仪表盘。Twin、预测、口碑→任务、10 种已验证语言。

## 什么让盈利可信

1. 第 0 周基线（scorecard）。  
2. 30 天后节省高管时间 + 降低事件风险。  
3. 清晰 USD：Pilot **$5,000** → Network **$1,000**/酒店/月。  
4. 模块化：为实际运行的部分付费——不是「签约日就要全部」。

## 全系统还是一部分？

**先一部分。** Wedge（简报 + 事件 + HITL）→ 衡量 → Land & Expand。  
正确集成 = **在 PMS 之上**，而不是取代它。
