## Открытие

HotelOS AI — не очередной чат-бот для отеля. Это **Intelligence Layer**: операционная система для сети над существующим PMS — с измеряемым пилотом до расширения доменов.

## Четыре опоры

### Возможности
ОС для сети — не ещё одно приложение отдела.  
Executive, Admin, Work и Guest на одном ядре. Брифинг, Incident Center, прогноз, предиктивное ТО, выручка с HITL, мультиязычный чат и агенты через один AI Gateway.

### Надёжность
AI предлагает — человек утверждает — система исполняет.  
Suggest → Approve → Act для денег и тарифов. Без чёрного ящика. Так сеть закрывает пилот без страха финансового комитета.

### Стабильность
Слой над PMS — не 18-месячный rip-and-replace.  
Opera / Protel / Fidelio / Clock остаются источником истины по броням. Меньше риска внедрения, быстрее ценность.

### Инновации
Строится как категория: Intelligence Layer для отелей.  
Не ChatGPT на Excel и не вчерашний дашборд. Twin, прогноз, репутация→задача, 10 проверенных локалей.

## Что делает прибыльность убедительной

1. Baseline на неделе 0 (scorecard).  
2. Экономия времени руководства + меньше риска инцидентов через 30 дней.  
3. Понятный USD: Pilot **$5,000** → Network **$1,000**/отель/месяц.  
4. Модульность: платите за то, что работает — не за «всё в день подписания».

## Вся система или часть?

**Сначала часть.** Wedge (брифинг + инциденты + HITL) → измерение → Land & Expand.  
Правильная интеграция = **над** PMS, не вместо него.
