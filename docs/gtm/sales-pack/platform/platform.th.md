## เปิดเรื่อง

HotelOS AI ไม่ใช่แชตบอตโรงแรมอีกตัว แต่สร้างเป็น **Intelligence Layer**: ระบบปฏิบัติการสำหรับเครือโรงแรมเหนือ PMS เดิม — พร้อมไพลอตที่วัดผลก่อนขยายโดเมน

## สี่เสาหลัก

### ความสามารถ
OS สำหรับเครือ — ไม่ใช่แอปแผนกเดียว  
Executive, Admin, Work, Guest บนคอร์เดียว Briefing, Incident Center, พยากรณ์, บำรุงรักษาเชิงคาดการณ์, รายได้พร้อม HITL, แชตหลายภาษา และเอเจนต์ผ่าน AI Gateway เดียว

### ความน่าเชื่อถือ
AI เสนอ — คนอนุมัติ — ระบบทำ  
Suggest → Approve → Act สำหรับเงินและเรท ไม่มีกล่องดำ เครือจึงปิดไพลอตได้โดยไม่กลัวคณะกรรมการการเงิน

### เสถียรภาพ
ชั้นเหนือ PMS — ไม่ใช่โปรเจกต์เปลี่ยนระบบ 18 เดือน  
Opera / Protel / Fidelio / Clock ยังเป็นแหล่งความจริงของการจอง ความเสี่ยงติดตั้งต่ำ มูลค่าเร็วขึ้น

### นวัตกรรม
สร้างเป็นหมวด: Intelligence Layer สำหรับโรงแรม  
ไม่ใช่ ChatGPT บน Excel หรือแดชบอร์ดเมื่อวาน Twin, พยากรณ์, ชื่อเสียง→งาน, 10 ภาษาที่ verified

## อะไรทำให้ความคุ้มค่าน่าเชื่อ

1. Baseline สัปดาห์ 0 (scorecard)  
2. เวลาผู้บริหารลด + ความเสี่ยงเหตุการณ์ลดหลัง 30 วัน  
3. ราคา USD ชัด: Pilot **$5,000** → Network **$1,000**/โรงแรม/เดือน  
4. โมดูลาร์: จ่ายเฉพาะที่รัน — ไม่ใช่ «ทั้งหมดวันเซ็น»
