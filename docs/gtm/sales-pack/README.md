**שימוש:** ייצוא ל־PDF (Print) · שליחה לוועדת רכש / משקיע בלי לשלוח ל־GitHub repo.  
**כלל:** אין SOC2 / ISO / לוגואים / ROI / ARR מומצאים.

## איך מייצרים PDF

1. פתחו את קובץ ה־HTML ב־`apps/www/public/sales-pack/` אחרי `pnpm dev:www`  
   או את ה־Markdown ב־GitHub → Print  
2. מדפסת → «Save as PDF» / «הדפסה לקובץ»  
3. שמרו ב־Drive/Notion הפרטי של הרשת (לא חובה ב־git)
