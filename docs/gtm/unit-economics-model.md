## Core formulas

```text
Gross Margin % = (ACV − COGS) / ACV
COGS ≈ infra + AI tokens + support allocation + payment fees
CAC = sales&marketing spend / new logos (period)
Payback (months) = CAC / (ACV × Gross Margin % / 12)
LTV (simple) = ACV × Gross Margin % × expected years
LTV:CAC target early stage ≥ 3:1 (direction, not law)
```
