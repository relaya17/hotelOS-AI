# Pilot playbook — HotelOS AI (4 weeks)

**Audience:** Hotel GM / COO / chain ops lead  
**Outcome:** Measured proof above existing PMS — no rip-and-replace.

## Roles

| Role | Responsibility |
|------|----------------|
| Hotel champion | Daily login, approve HITL when needed |
| HotelOS success | Setup, training, scorecard |
| IT / PMS owner | Read access / exports as agreed — no silent PMS writes |

## Week plan

| Week | Focus | Done when |
|------|-------|-----------|
| 0 | Connect hotel · fill baseline on [pilot-roi-scorecard.md](../planning/pilot-roi-scorecard.md) | Scorecard week-0 complete |
| 1–2 | Executive briefing + Incident Center live | Champion uses briefing ≥3 mornings |
| 3 | Optional: upsell / reputation / predictive maint | Domain agreed in writing |
| 4 | Re-measure · expand / pause decision | Scorecard + go/no-go note |

## Success criteria (pick 3+)

- Briefing prep time ↓ vs baseline  
- Median urgent incident response time ↓  
- Room prep waiting→ready improved  
- Upsell accept rate tracked (if in scope)  
- Champion wants Network expand

## Non-goals for pilot

- Replacing Opera/Protel/Fidelio/Clock  
- Unattended rate writeback to PMS  
- Claiming SOC2/ISO during pilot

## Exit / expand

| Decision | Next |
|----------|------|
| Expand | Network package · next hotels · domains |
| Pause | Keep read-only lessons · optional retainer discovery |
| Stop | Export scorecard · offboard access |
